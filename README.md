# 模块 1 复习笔记站

把秋 1–8 已提供的课件压缩成 **85 个知识点 / 349 道练习 / 125 张课件原图 / 67 张对比表** 的离线复习站。**双击 `index.html` 即可打开**，无需服务器、无需联网（`file://` 下所有功能正常）。

## 怎么用

| 操作 | 说明 |
|---|---|
| 左侧目录树 | 按 **模块 → 周 → 知识点** 三级展开，点标题跳转 |
| 顶部搜索框 | 实时过滤知识点标题与正文（如输入"阿托品""半切"） |
| `只看高频考点` | 只留下带 `高频考点` 标签的知识点 |
| `←` / `→` | 上一个 / 下一个知识点 |
| 每题点选项 | **立即判分**并显示解析与该题来源；错题不能重选，`重置` 清空 |
| `标记为已复习` | 知识点级勾选，侧栏进度条随之增长 |
| 点配图 | 放大查看（`Esc` 或点背景关闭） |
| `打印`（浏览器 Ctrl+P） | 侧栏自动隐藏、所有答案解析强制展开、对比表不跨页断行，可直接导出 PDF |
| 右上 `刷题 →` | 进入独立的刷题版块（见下） |

学习进度与答题记录存在浏览器 `localStorage`（键 `m1notes.progress.v1`、`m1notes.kpdone.v1`），换电脑不会同步，也不会丢你的原始数据。

## 刷题版块（quiz.html）

**与笔记页同目录、独立入口**：笔记页右上角 `刷题 →`，或直接双击 `quiz.html`。题库来自开源数据集 [CMExam](https://github.com/williamliujl/CMExam)（NIPS 2023 D&B，Apache-2.0，中文执业医师资格考试多选题），**三份分片全部合并去重后共 66,763 题**。

| 功能 | 说明 |
|---|---|
| **按人体系统归类** | 14 个系统 + 8 个跨系统类别（感染、肿瘤、损伤中毒、口腔、中医、药学、公卫法规、医学基础），侧栏显示各类题量；**每一题都归了类** |
| **难度** | 用数据集自带的 1–5 级（★～★★★★★）。注意只有 test 分片带这个标注，其余 59,966 题显示「难度未标注」，可单独筛选 |
| **题型** | 单选 64,608 题、多选 2,155 题（多选需点「提交答案」） |
| **四种模式** | 顺序刷（按系统分组排序）／随机 20 题／错题重做／未做过的 |
| **分片加载** | 题库按系统切成 22 个 JS 分片，**选中哪个系统才载入哪个**；点「全部系统」时顺序载入 22 组（本机约 1.2 s） |
| **作答反馈** | 立即判分：绿色＝正确项，红色＝你选错的项；显示**你的答案 / 正确答案**与数据集原始解析（56,928 题有解析） |
| **标签** | 每题显示 系统 · 难度 · 题型 · 科室 · 学科 · 胜任力 · 疾病分组（后几项来自 test 分片的标注，无则省略） |
| **键盘** | `A`–`E`（或 `1`–`5`）选项 · `Enter` 提交/下一题 · `←` `→` 翻页 |
| **进度** | 存在 `m1quiz.v1`（键 `r` 对错、`c` 所选项），可重置；侧栏实时显示已答数与正确率 |

> 题库里也有中医、口腔、药学与公卫法规题 —— 执业医师考试本来的构成就是这样，它们被单独归到「跨系统」类别，不影响按系统刷。**这些题与本院课件无关，只做补充练习**。

```

├── quiz.html       刷题页骨架

├── quiz.js         刷题逻辑（筛选、判分、进度、键盘、分片加载）

└── README.md
```

## 每个知识点长什么样

- **一句话结论**（`one`）：先看这一句，能回忆起来就跳过。
- **标签**：`生理学` `神经生物学` `药理学` `神经病学` `行医学` `骨科学` `病理学` `影像学` 中 1–2 个专业标签 + **恰好一个**掌握层级（`掌握` `熟悉` `理解` `了解`）+ 可选 `高频考点`。
- **要点 3–6 条**：每条末尾都有**来源页**（如 `张世红·胆碱能 p28`、`吴志英·脑神经 p21–22`），方便回原课件核对。关键词用**加粗**标出。
- **配图 0–2 张**：直接从课件页或 PPT 媒体库取出，图注写"这张图说明了什么"。（PPTX/PPT 现在也会逐页导出成 `pages/pNNN.png`，所以幻灯片也能像 PDF 一样按页配图。）
- **对比表 0–2 张**（可选）：几项之间的横向对照（受体分型、疾病鉴别、药物对比）用表格表达，比堆要点省地方又好背；出处同样标在表下。
- **练习 2–5 题**：四选一，答对即时解析；`src` 标明出处，课件原题写 `课件·<讲者> pNN`，自编题写 `自编·依据 <讲者> pNN`，网上找来的现成题写 `网络·<来源> <链接>`。

图例：`⚠︎` 无——本站在要点中使用 `**加粗**` 表示**课件红字/加粗/下划线标注过的内容**，也就是老师真正强调的部分。

## 改内容 / 重新生成

数据由构建脚本合并，**不要手改 `data.js`**：

```powershell
cd _tooling
node extract.mjs          # ① 解析新增课件（PDF/PPTX/PPT/DOC/DOCX/RAR/ZIP）→ _extracted/
node emphasis.mjs ..      # ② 重提红字/加粗/下划线标注 → _extracted/_emphasis.json
node render_pptx.mjs      # ③ 给 PPTX/PPT 逐页导出渲染图 → pages/pNNN.png（配图与页号引用需要它）
node build_notes.mjs      # ④ 合并 _notes_parts/*.json → 笔记网站/data.js，并复制配图
node check_notes.mjs      # ⑤ 数据体检：标签、题量、答案下标、表格列数、覆盖统计
node test_site.mjs        # ⑥ jsdom 冒烟测试 + 静态 CSS 检查（含 hidden 兜底规则）
node shot.mjs             # ⑦ 真实浏览器截图，UI 改动后用它看实际效果（输出到 _tooling/_shots/）
node schedule.mjs         # ⑧ 打印教学日历课表，核对哪些讲次还没拿到课件
node validate_parts.mjs   # ⑨ 逐分片体检：配图 PNG 是否真实存在、表格列数、题量上限
node _digest.mjs "<_extracted 目录名>" 240   # 把课件压成「逐页一行」摘要，快速通读 100+ 页
node _figcheck.mjs chk.png "<目录>" "22,41"  # 把要引用的页拼成一张对照图，核对配图与图注
node build_quiz.mjs       # ⑩ 重建题库：_quiz/*.csv（三份分片）→ quiz-data.js 索引 + quiz-q/*.js
node test_quiz.mjs        # ⑪ 刷题页冒烟测试（22 项：分片加载、判分、筛选、模式、进度）
node fix_quotes.mjs ..\_notes_parts\XX.json   # 修 JSON 里误用的 ASCII 引号
```

刷题页的数据来源是 `_quiz/` 下 CMExam 官方发布的三份分片（Apache-2.0）：`test_with_annotations.csv`（5.6 MB，**带 5 个标注列**）、`val.csv`（4.9 MB）、`train.csv`（38.7 MB），合并去重后 66,763 题。`build_quiz.mjs` 做的事**全部是规则、零模型调用**：

1. 解析 CSV —— 这份数据正文里夹着**裸 ASCII 引号**，所以只在**字段开头**才把 `"` 当引号（否则解析器会卡在引号里吞掉几万行）；
2. 归类 —— ICD 疾病分组表 → 关键词规则（题干优先，其次选项文本）→ 科室兜底，**每题都落到 22 个类别之一**；
3. 标注 —— test 分片自带的难度/科室/学科/胜任力/疾病分组原样保留，`不符合` 视为缺失；val、train 没有标注就留空；
4. 输出 —— 索引 `quiz-data.js`（几十 KB）+ 按系统切片的 `quiz-q/NN.js`（共 42 MB），前端选中哪个系统才注入哪个分片。

想换题库：把 CSV 放进 `_quiz/`，改 `build_quiz.mjs` 里的 `SPLITS` 与 `RULES` 规则表，重跑即可。

> ⚠️ 改 CSS 时注意：如果用 `hidden` 属性控制显隐，**不要再给同一个元素写 `display:`**——作者样式会压掉浏览器默认的 `[hidden]{display:none}`，元素将永远显示（例如 `display:flex` 的全屏遮罩会盖死整个页面）。必须补一条 `.类名[hidden]{display:none}`。`test_site.mjs` 已对此做静态检查。

新增知识点：在 `_notes_parts/` 放一个 `{"kps":[...]}` 分片（字段规范见 `_notes_parts/_SPEC.md`），重跑构建即可。`build_notes.mjs` 会校验字段、标签、答案下标与配图路径，出错直接退出并列出原因。
